# Extreme Fitness Gym — Demo Website

A responsive static website concept for Extreme Fitness Gym, Madiyanva, Lucknow. Built with plain HTML, CSS and JavaScript; no framework or build step is required.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. An internet connection is needed for Google Fonts and the sample Unsplash images.

## Publish on GitHub Pages
1. Create a GitHub repository (or use the existing portfolio repository if appropriate).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In GitHub, open **Settings → Pages**, choose the deployment source, and publish.
4. Test the published page on both mobile and desktop.

## Before showing it as a real gym website
- Confirm the business name, spelling, address, phone, hours, services and membership prices with the owner.
- Replace sample/stock images with gym photos that the owner has approved for use.
- Replace the illustrative membership prices with verified current prices—or remove them.
- Add official social profile URLs and the official email in `script.js` under `GYM_CONFIG`.
- The enquiry form uses `mailto:` only after a valid email is configured. It does not store or submit data to a server. For a production form, connect a trusted form backend and add appropriate privacy information.
- Add real trainer profiles, testimonials and claims only after receiving permission and verifying details.
- Test links, keyboard navigation, image loading, mobile layout and form behaviour before launch.

## Demo notes
- Prices, photos, statistics and trainer details are illustrative/demo content, not verified facts about the gym.
- Social links are intentionally unconfigured rather than linking to guessed profiles.
- No client data is collected by this static demo.
